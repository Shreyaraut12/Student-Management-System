# 🎓 Student Management System

A simple Spring Boot CRUD application for managing student records using MySQL, Thymeleaf, Bootstrap, and Spring Data JPA.

## ✨ Features

- Add Student
- View Students
- Update Student Details
- Delete Student
- Responsive Bootstrap UI
- MySQL Database Integration

## 🛠 Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- MySQL
- Bootstrap 5
- Maven

## 📂 Project Structure

- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer
- Thymeleaf Templates

## ▶️ Run the Project

1. Clone the repository
2. Configure MySQL in `application.properties`
3. Run `SmsApplication.java`
4. Open browser:
